## 6. 验收清单

账号：测试环境 CAS（如 `18273702222`）。浏览器 **不要** 把 `zsk.t.nxin.com` hosts 到本机。

| # | 项 | 期望 |
|---|----|------|
| 1 | 登录后打开 `?tab=mydocs` | 见「我的文档」tab 与面板 |
| 2 | 我的文件 / 与我共享 | 可切换，树接口 200 |
| 3 | 新建文件夹 → 重命名 → 归档 | 归档后默认树消失 |
| 4 | 上传 txt/md | 列表可见；可预览 |
| 5 | 分享 viewer | 对方「与我共享」可读；不可写 |
| 6 | `GET /api/v1/my-docs/tree`（带 CAS Cookie） | 非 401/503；有数据或空数组 |
| 7 | MCP catalog | 端点工具组含 `mydoc_*`（可选抽测） |

失败定位：

- `401 missing authentication`：Cookie 未带到 zsk，或 `nxin_cas_auth` 未开。
- `503 Auth provider unavailable`：CAS 用户中心换档失败（测试机 UC/`open.t.nxin.com`/Redis）；与 MyDoc 业务无关，先修 CAS 鉴权。
- 表不存在：DDL 未执行。
