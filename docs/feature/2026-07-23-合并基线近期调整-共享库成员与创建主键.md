## 2. 共享知识库成员入口（本次主修）

### 2.1 产品语义

- **成员**（`KnowledgeBaseMembers`）：广场/直接共享库的库级成员（owner/editor/viewer）。
- **共享管理**（`KBShareSettings`）：共享到「共享空间 / Organization」的 ACL。
- 二者同属「发布集成」，**不可互相替代**。

### 2.2 显示条件（勿改松）

```
mode === 'edit' && visibility === 'shared' && is_owner
```

`is_owner`：接口 `is_owner` **或** `owner_id === 当前用户`。

### 2.3 合并时核对口诀

```
官方改了 KnowledgeBaseEditorModal 侧栏分组？
  → integration 组 keys 必须含 members（在 share 前）
  → 以 KB_EDITOR_INTEGRATION_NAV_KEYS 为准，禁止只写 ['share']
```

### 2.4 手工验收（测试环境 / 本地）

1. 打开共享知识库「甲骨文研学」类库（`visibility=shared`，本人为 owner）。
2. 知识库设置 → 左侧「发布集成」应同时出现：**成员**、**共享管理**。
3. 点「成员」→ 列表非空（至少含 owner）；可搜、改角色、移除（非 owner）。
4. 私有库：侧栏**不应**出现「成员」。
