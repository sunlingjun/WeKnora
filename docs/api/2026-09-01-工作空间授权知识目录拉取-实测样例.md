要点：

- 自有库 `owner_tenant_id` 等于当前空间 `10384`；分享库归属 `10025`，带 `organization_id` / `share_id`。
- FAQ 库会出现在目录里（`type=faq`），`knowledge_count=0` 时下一步扫知识会得到空 `items`。
- 组织分享 `permission=viewer` → **可以按 `kb_id` 列知识，禁止 download**。
