# 工作空间授权知识目录拉取 — 调用示例

[返回目录](./README.md)

**确定方案**：[工作空间授权知识目录拉取设计](../feature/2026-08-31-工作空间授权知识目录拉取设计.md)  
**可运行脚本**：`scripts/2026-09-01-knowledge-catalog-sync.py`  
**生产实测样例**：[2026-09-01-工作空间授权知识目录拉取-实测样例.md](./2026-09-01-工作空间授权知识目录拉取-实测样例.md)

远端只用这一条顺序。不要拼现网 `/knowledge-bases` + `/shared-knowledge-bases` + `/:id/knowledge`，也不要读 `file_path` 去拼存储地址。

```text
1. GET /api/v1/knowledge-catalog/knowledge-bases
2. 对每个 kb_id：循环 GET /api/v1/knowledge-catalog/knowledge?kb_id=&cursor= 直到 has_more=false
3. 仅当该库 can_download=true 且 knowledge_type=file（且 has_file=true）：
     GET /api/v1/knowledge/{id}/download
```

## 凭证

| 项 | 值 |
|----|----|
| Header | `X-API-Key: <空间绑定 Key>` |
| 能力 | `retrieve` 或 full-access |
| 空间 | Auth 注入的 tenant（Key 所属工作空间）。**不要**传 `X-Tenant-ID` / query `tenant_id` |
| 白名单 | Key 的 `knowledge_base_ids` 非空时，目录和知识两层都裁。要同步组织分享库，须把那些 id 写入白名单，或用空白名单 |

```powershell
$env:WEKNORA_HOST = "http://127.0.0.1:8080"
$env:WEKNORA_API_KEY = "sk-xxxxx"
$Base = "$env:WEKNORA_HOST/api/v1"
$Headers = @{ "X-API-Key" = $env:WEKNORA_API_KEY }
```

## 1. 拉库目录

```bash
curl -sS "$WEKNORA_HOST/api/v1/knowledge-catalog/knowledge-bases" \
  -H "X-API-Key: $WEKNORA_API_KEY" \
  -H "Accept: application/json"
```

可选 query：`include_org_shared=true`（默认）、`type=document|faq|wiki`。

成功体（字段以服务端为准；**没有** `file_path` / `vector_store_id`）：


记住每条的 `id`、`owner_tenant_id`、`can_download`。`org_share` 且 `permission=viewer` 时 **只列知识，禁止 download**。

校验响应不含存储路径（PowerShell）：

```powershell
$catalog = Invoke-RestMethod -Headers $Headers "$Base/knowledge-catalog/knowledge-bases"
$json = $catalog | ConvertTo-Json -Depth 10
if ($json -match "file_path" -or $json -match "vector_store_id") { throw "catalog leaked storage fields" }
```

## 2. 按 kb_id 游标扫知识

`kb_id` **必填**。缺省 400；不在授权集合 404（不泄露跨空间存在性）。`limit` 默认 100，范围 1–500。游标不透明，原样回传 `next_cursor`。

```bash
cursor=""
kb_id="kb-own-1"
while :; do
  if [ -n "$cursor" ]; then
    qs="kb_id=${kb_id}&limit=100&cursor=${cursor}"
  else
    qs="kb_id=${kb_id}&limit=100"
  fi
  page=$(curl -sS "$WEKNORA_HOST/api/v1/knowledge-catalog/knowledge?${qs}" \
    -H "X-API-Key: $WEKNORA_API_KEY")
  echo "$page"
  has_more=$(printf '%s' "$page" | python -c "import json,sys; d=json.load(sys.stdin)['data']; print(str(d.get('has_more')).lower())")
  cursor=$(printf '%s' "$page" | python -c "import json,sys; print(json.load(sys.stdin)['data'].get('next_cursor') or '')")
  [ "$has_more" = "true" ] || break
done
```

PowerShell：

```powershell
function Get-CatalogKnowledge([string]$KbId) {
  $cursor = ""
  do {
    $url = "$Base/knowledge-catalog/knowledge?kb_id=$KbId&limit=100"
    if ($cursor) { $url += "&cursor=$([uri]::EscapeDataString($cursor))" }
    $page = Invoke-RestMethod -Headers $Headers $url
    $raw = $page | ConvertTo-Json -Depth 10
    if ($raw -match "file_path" -or $raw -match "vector_store_id") { throw "knowledge list leaked storage fields" }
    $page.data.items
    $cursor = $page.data.next_cursor
  } while ($page.data.has_more)
}

Get-CatalogKnowledge "kb-own-1"
Get-CatalogKnowledge "kb-share-9"   # 分享库也能列出元数据；下一步不要 download
```

## 3. 仅可下载的 file 走现网 download

条件必须同时成立：

- 该库 `can_download=true`（自有库 + 空间 Key 为 true；组织分享 viewer 为 false）
- `knowledge_type=file`
- 建议再判断 `has_file=true`（没有源文件的 file 行 download 会失败）

```bash
curl -sS -OJ "$WEKNORA_HOST/api/v1/knowledge/${KNOWLEDGE_ID}/download" \
  -H "X-API-Key: $WEKNORA_API_KEY"
```

PowerShell（按 Content-Disposition 落盘）：

```powershell
Invoke-WebRequest -Headers $Headers `
  -Uri "$Base/knowledge/$KnowledgeId/download" `
  -OutFile ".\报销制度.pdf"
```

响应是 **二进制**（`Content-Type: application/octet-stream`），不是 JSON。  
分享 viewer / JWT Viewer 调 download 会 **403**，不要靠试错。

## 一键跑通

连本机 WeKnora（需已启动且二进制含 Catalog 路由，Key 具备 `retrieve`）。本地 HTTPS 自签证书加 `--insecure`：

```powershell
$env:WEKNORA_HOST = "https://127.0.0.1:8080"
$env:WEKNORA_API_KEY = "sk-xxxxx"
python scripts/2026-09-01-knowledge-catalog-sync.py --insecure --out .\tmp\catalog-files
```

只扫目录、不落文件：

```powershell
python scripts/2026-09-01-knowledge-catalog-sync.py --skip-download
```

## 错误

| HTTP | 情况 |
|------|------|
| 401 | 未带 Key / Key 无效 |
| 403 | Key 无 `retrieve`、未登记路由、对 `can_download=false` 的库撞 download |
| 400 | 缺 `kb_id`、`limit` 非法、`updated_after` 非法 |
| 404 | `kb_id` 不在当前空间授权集合（含已取消的组织分享） |

空目录是 `200` + `knowledge_bases=[]`，不是 404。
