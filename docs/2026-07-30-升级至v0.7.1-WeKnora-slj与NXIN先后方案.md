# 2026-07-30 升级至上游 v0.7.1：WeKnora-slj → NXIN-WEKNORA（方案 1）

> **目标 Tag（腾讯官方）**：`Tencent/WeKnora` **`v0.7.1`**（`VERSION=0.7.1`，约 2026-07-24）  
> **当前稳定基线**：`nxin-v0.7.0-stable.1` @ `68a800ea` / 分支 `stable/2026-07-20-nxin-v0.7.0`  
> **策略**：沿用 0.7.0 **先后模型**——先在 WeKnora-slj merge 官方并保留自研，打出 `nxin-v0.7.1-stable.*`；NXIN-WEKNORA **简单合入**该稳定版，**不再**在 NXIN 分支做业务/构建回灌。  
> **新能力**：代码随版本带上；云之家 / 平台 API Key / 智谱搜索等 **按需后开**（不强制现网开通）。  
> **Neo4j**：仅下线「会话记忆」；**GraphRAG 知识图谱继续启用**，勿停 Neo4j。  
> **Langfuse**：升前核查 env/设置；若在用则迁 OTLP。

## 3. Phase B — NXIN-WEKNORA（简单合入）

### 3.1 目标形态

```text
git fetch upstream --tags   # 或 weknora-slj
git checkout dev
git merge nxin-v0.7.1-stable.1
# 期望：无业务冲突；仅注意未跟踪 .env* 不被覆盖
# 禁止：再改 auth/CAS/Dockerfile「补 NXIN 洞」——洞应回 slj
```

若历史噪声导致 merge 困难，允许：

```text
git checkout -B upgrade/from-nxin-v0.7.1-stable.1 upstream/nxin-v0.7.1-stable.1
# 仅拷回本机未入库的 .env.test / .env.prod / frontend/.env.*
```
